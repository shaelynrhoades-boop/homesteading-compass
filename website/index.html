The Waystation

Local tools for neighbors, sellers, and makers.

Waystation features help users publish homestead profiles, find local stands, browse seller inventory, message safely in-app, and keep listings connected to records already saved in the app.

  • Trading Post listings can pull from Farm Stand and livestock records.
  • Outpost profiles organize public business/service information.
  • Front Porch Hub supports questions, events, and local knowledge.
  • Porch Light Map groups Farm Stand, Trading Post, Outpost, and homestead pins.

Porch Light Map

Map pins open grouped inventory, seller details, and visit/message actions.

Subscription Tiers

Start simple, unlock business tools as the homestead grows.

Backyard

Basic homestead planning for smaller setups.

  • Core Almanac access
  • Basic To Do and recipe entries
  • Private records with starter limits

Hobby Farm

For working homesteads that need more logs and local visibility.

  • Trading Post and Outpost browsing
  • One Farm Stand setup
  • More log capacity and connected reminders

Homesteader

For users who need broader records and publishing tools.

  • Expanded Farm Stand tools
  • More public selling and publishing options
  • Higher limits for active records and workflows
